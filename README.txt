NestMap – wersja do testów

1. Rozpakuj ZIP.
2. Najlepiej uruchom przez prosty serwer HTTPS/HTTP (np. GitHub Pages, Netlify lub lokalny serwer), ponieważ geolokalizacja i Service Worker wymagają bezpiecznego kontekstu.
3. Otwórz index.html.

Nowy nagłówek używa dokładnie przesłanego obrazu „logo NestMap.jpg” jako grafiki kani i gniazda. Nie modyfikowano obrazu.

Dane gniazd są zapisywane lokalnie w przeglądarce (localStorage). Aplikacja nie synchronizuje ich z serwerem.
